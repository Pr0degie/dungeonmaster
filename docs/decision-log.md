# Decision log — index to the ADRs

Moved out of `progress.md` on 2026-10-25 to keep the live status file small; the `D##` numbers
are unchanged, so every "decision log DX in progress.md" reference in an older ADR resolves here.
Read on demand: `grep -n "| D87 |" docs/decision-log.md`, never the whole file.

Each row with a real trade-off links its decision to a full ADR under `docs/decisions/` (the
`→ ADR NNN` at the end). To find the ADRs that govern a phase, use the **phase → ADR map** in
`progress.md`. A new non-trivial decision gets the next `D##` row here and the next-numbered ADR;
rows with an ADR stay at most two lines (what + one-clause why + → ADR NNN).
